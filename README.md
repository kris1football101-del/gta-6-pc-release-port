## 📖 What is this?

**GTA-6-PC-Release-Port-Via-Reverse-Engineering** is a **release-grade** PC port of **GTA 6**, produced entirely through manual reverse engineering — no emulator front-end and no black-box AI layer sitting in the middle.

The console binary is taken apart by hand: symbols are reconstructed, call signatures are mapped, and the hot paths are statically recompiled into native x86-64 host code. A detour layer bridges what cannot be recompiled cleanly — graphics API, input, audio and file IO — while the original game data stays read-only.

The result ships as a **versioned release**: an installer, a small update patcher for new game patches, and a debug overlay with a profiler and log console for anyone who wants to follow the work.
